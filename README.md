# HytaleVehicles

Adds rideable vehicles to Hytale - cars, boats, motorcycles and more.

## Features (Planned)

- **Phase 1**: Rideable animals, simple boats, animal stables
- **Phase 2**: Motorcycles, bicycles, carts
- **Phase 3**: Cars, trucks, advanced vehicles

## Requirements

- Java 25+
- Hytale Server

## Building

```bash
./gradlew build
```

Output JAR will be in `app/build/libs/HytaleVehicles-1.0.0.jar`

## Installation

Copy the JAR to `%appdata%/Hytale/UserData/Mods/`
